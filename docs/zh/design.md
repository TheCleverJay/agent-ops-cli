# 设计说明

## 为什么是这六个命令

Agent 主机的翻车方式很固定。每个子命令对应一种：

| 翻车 | 命令 |
|---|---|
| 上下文膨胀 / 过早压缩 | `budget` |
| 前台 shell 卡住整轮对话 | `watch` |
| 排障时把密钥打到日志 | `env-audit` |
| 本该安静的例行任务刷屏 | `log-digest` + `routine-lint` |
| 「附属服务还活着吗」 | `health` |

## 有意保持的约束

- **零运行时依赖**——安装摩擦会杀死运维工具。
- **退出码贴近 Unix 肌肉记忆**（`124` 超时族）。
- **`env-audit` 永不打印密钥值**。
- **公开树拒绝专有/付费附件**。

## 不会加什么

进程守护、云端 Agent 调度器、券商适配、带落盘加密的密钥库，或任何需要常驻守护进程的东西。CLI 保持无聊、可脚本化。
